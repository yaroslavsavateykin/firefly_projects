# Практикум 2. Кривые потенциальной энергии H2

## Цель

Построить и сравнить потенциальные кривые H2 в минимальном базисе STO-3G методами RHF и full CI, чтобы увидеть ошибку RHF при растяжении связи и роль конфигурационного взаимодействия.

## Что требуется посчитать

- Серию одноточечных RHF/STO-3G расчетов H2 по межъядерному расстоянию.
- Такую же серию full CI/STO-3G расчетов с `CITYP=ALDET`, `NACT=2`, `NELS=2`.
- Получить энергии для построения двух кривых и сравнения диссоциационного поведения.

## Папка запуска

Вся серия лежит в одной папке `h2_curve`. Файлы `h2_rhf_R_*.inp` соответствуют RHF-точкам, `h2_fci_R_*.inp` - full CI-точкам. Расстояния: `0.40`, `0.50`, `0.60`, `0.70`, `0.80`, `1.00`, `1.20`, `1.50`, `2.00`, `3.00`, `5.00` Angstrom.

## Запуск

```bash
./run_all.sh
```

Input-файлы можно заново создать простой командой:

```bash
cd h2_curve
python3 make_inputs.py
```

## Основные файлы

- `h2_curve/make_inputs.py` - небольшой генератор только для input-файлов H2-скана.
- `h2_curve/h2_rhf_R_*.inp` - RHF-точки.
- `h2_curve/h2_fci_R_*.inp` - full CI-точки.
- `.out` и `.dat` рядом с каждым input-файлом - основные результаты Firefly.

## Что сделано

Скан организован одной простой серией без вложенных папок: все input/output лежат в `h2_curve`, запуск идет циклом по `*.inp` через штатный Firefly/P4 `-p4pg`. По умолчанию в `run.sh` задано `NP=10`. Синтаксис full CI взят из старого `~/historical projects/prak2/h2_surface_fullci`.
