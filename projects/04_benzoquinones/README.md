# Практикум 4. Бензохиноны

Рабочий конвейер для p-бензохинона и o-бензохинона на урезанном
Andrew-style базисе. Базисные блоки C/O/H печатаются прямо в `$DATA`;
внешний `$BASIS EXTFIL` не используется.

Итоговый размер базиса во всех финальных расчетах: 160 функций. По смыслу
это прежняя рабочая схема: cc-pVDZ-уровень для C/H и расширенный
aug-cc-pVDZ-тип блока для кислородов.

## Метод

Для каждого изомера:

1. MP2 geometry optimization: `NSTEP=100`, `TRMAX=0.5`, `OPTTOL=1E-04`.
2. CIS на стартовой геометрии.
3. CIS на реально найденной MP2-геометрии.
4. XMCQDPT2/ALDET-CASSCF(12,10) на MP2-геометрии.

Активное пространство:

```text
$DET NCORE=22 NACT=10 NELS=12 NSTATE=15 WSTATE(1)=1,1,1,1,1
$MCSCF CISTEP=ALDET
$XMCQDPT NSTATE=5 EDSHFT=2D-2 WSTATE(1)=1,1,1,1,1
```

Финальные XMC-расчеты были доведены до нормального завершения с ослабленными
MCSCF-критериями: для `p_bq` `ACURCY=5D-2 ENGTOL=1D-2`, для `o_bq`
`ACURCY=5D-3 ENGTOL=1D-3`.

## Структура

```text
p_bq/
  01_mp2_opt/
  02_cis/
  03_cis_opt_geometry/   # пересобирается после MP2
  04_xmcqdpt2/

o_bq/
  01_mp2_opt/
  02_cis/
  03_cis_opt_geometry/
  04_xmcqdpt2/
```

`scripts/build_andrew_style.sh` создает inputs на встроенном урезанном базисе,
а после MP2 извлекает финальную геометрию из `.out` и строит стадии `03` и
`04`.

## Запуск

```bash
bash run_all.sh
```

`run_all.sh` запускает p-BQ и o-BQ параллельно. Внутри каждого изомера стадии
идут последовательно. По умолчанию каждый Firefly job использует `NP=6`.

Для другого числа ядер:

```bash
NP=8 bash run_all.sh
```

XMCQDPT2-стадия использует CAS(12,10), `NORB=160` и CIS `$VEC` на
MP2-оптимизированной геометрии.
