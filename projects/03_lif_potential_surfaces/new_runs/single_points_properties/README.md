# LiF single-point property calculations

This branch is separate from the surface scans. It is used to obtain properties
that were not printed by `RUNTYP=SURFACE`: dipole moments, Mulliken/Lowdin
charges, natural occupations, spin labels, and determinant CI coefficients when
Firefly prints them.

Inputs are generated by `generate_sp_inputs.py` from the existing LiF ALDET setup:

- `CITYP=ALDET`
- `SCFTYP=RHF`
- external `aug-cc-pVDZ` basis
- `NCORE=3`, `NACT=29`, `NELS=6`, `NSTATE=3`
- `RUNTYP=ENERGY`

No unverified property keywords are added. Local Firefly ALDET single-point
examples print `STATE ... S= ...` and `ALPH|BETA| COEFFICIENT` blocks using the
plain `$CIDET` setup, while LiF `RUNTYP=SURFACE` outputs do not.

Run:

```bash
MAX_PARALLEL=2 NPROC_PER_JOB=8 new_runs/single_points_properties/run_sp.sh
```

Use `--dry-run` to print commands and perform path/resource checks without
launching Firefly.
