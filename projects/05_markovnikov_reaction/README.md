# Prakt05 (Markovnikov): поиск переходного состояния для реакции HF + C3H6 (Марковниковское присоединение)

Практикум посвящён марковниковскому присоединению HF к пропену: фтор присоединяется к более замещённому атому углерода (C2), а водород — к концевому (C3).

## Общая схема работы

1. **Оптимизация геометрий концевых точек** (`new_file_opt_00/`, `new_file_opt_01/`).
   - `new_file_opt_00`: реагентная область (HF + C3H6)
   - `new_file_opt_01`: продукт С3H7F (марковниковский)

2. **Геодезическая интерполяция** — 11 кадров между двумя предельными структурами (`geodesic_interpolation.xyz`).

3. **Одноточечные DFT-расчёты энергии** для всех 11 точек:
   - `c3h7f_scan_00` — `c3h7f_scan_10` (11 кадров)

4. **Поиск максимума** на энергетическом профиле.

5. **Расчёт гессиана** в точке максимума (`c3h7f_hessian/`).

6. **Оптимизация седловой точки** с чтением гессиана (`c3h7f_sadpoint/`).

7. **IRC-расчёты** в обе стороны от переходного состояния:
   - `c3h7f_irc_step_19/` (FORWRD=.T.)
   - `c3h7f_irc_reverse_step_19/` (FORWRD=.F.)

## Метод и базис

- **Уровень:** B3LYP/aug-cc-pVDZ
- **Тип:** RHF (closed-shell), DFT B3LYP, заряд 0, мультиплетность 1
- **Программа:** Firefly 8.2.0

## Структура папок

```
05_markovnikov_reaction/
├── new_file_opt_00/           # оптимизация реагента
├── new_file_opt_01/           # оптимизация продукта (марковников)
├── c3h7f_scan_00..10/         # 11 одноточечных расчётов
├── geodesic_interpolation.xyz # 11 кадров интерполяции
├── generate_all.py            # генератор входных файлов
├── parse_energies.py          # анализатор энергий + генерация hessian/sadpoint/irc
├── run_all.sh                 # полный пайплайн
└── README.md
```

## Как запускать

```bash
# Полный пайплайн (сканы → hessian → sadpoint → IRC):
./run_all.sh

# Или пошагово:
python3 generate_all.py                        # генерация входных файлов
for d in new_file_opt_* c3h7f_scan_*; do
  (cd "$d" && ./run.sh)
done
python3 parse_energies.py --stage 1            # найти максимум
python3 parse_energies.py --stage 2            # сгенерировать hessian
(cd c3h7f_hessian && ./run.sh)
python3 parse_energies.py --stage 3            # сгенерировать sadpoint
(cd c3h7f_sadpoint && ./run.sh)
python3 parse_energies.py --stage 4            # сгенерировать IRC
(cd c3h7f_irc_step_19 && ./run.sh)
(cd c3h7f_irc_reverse_step_19 && ./run.sh)
```

## Ожидаемые результаты

После завершения всех расчётов `parse_energies.py --stage 1` выведет таблицу энергий всех 11 кадров. Точка с максимальной энергией — приближение к переходному состоянию. После уточнения через гессиан и SADPOINT ожидается одна мнимая частота 1584i cm⁻¹ (как и в анти-марковниковском варианте), подтверждающая переходное состояние.
