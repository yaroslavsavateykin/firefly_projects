# Практикум 1. Метод Хартри-Фока

## Цель

Освоить базовые расчеты RHF/UHF в Firefly: энергии и орбитали H2, влияние базиса, проверку теоремы Купманса, дипольный момент CO и сравнение канонических и локализованных орбиталей.

## Что требуется посчитать

- H2 методом RHF в STO-3G и сравнить энергию с 6-31G.
- Для H2/H2+ проверить теорему Купманса: сравнить `-epsilon(HOMO)` с `E(H2+) - E(H2)` в STO-3G и 6-31G.
- CO методом RHF в STO-3G и 6-31G, получить дипольный момент и число базисных функций.
- CH4, H2O и C2H4: получить канонические орбитали и орбитали после Boys-локализации (`LOCAL=BOYS`).

## Папки запусков

- `h2_rhf_sto3g` - нейтральный H2, RHF/STO-3G.
- `h2_rhf_631g` - нейтральный H2, RHF/6-31G.
- `h2plus_uhf_sto3g` - H2+, UHF/STO-3G.
- `h2plus_uhf_631g` - H2+, UHF/6-31G.
- `co_rhf_sto3g` - CO RHF/STO-3G, дипольный момент.
- `co_rhf_631g` - CO RHF/6-31G, дипольный момент.
- `ch4_canonical_sto3g`, `h2o_canonical_sto3g`, `c2h4_canonical_sto3g` - канонические орбитали.
- `ch4_boys_sto3g`, `h2o_boys_sto3g`, `c2h4_boys_sto3g` - Boys-локализованные орбитали.

## Запуск

Запустить все расчеты:

```bash
./run_all.sh
```

Или отдельный расчет из его папки:

```bash
./run.sh
```

## Основные файлы

Входные файлы имеют имена папок с расширением `.inp`. Результаты Firefly пишутся рядом: `.out` и `.dat`; runtime-модули `.ex` берутся из `shared/firefly/8.2.0` через `-ex`, scratch вынесен в `/tmp`.

## Что сделано

Input-файлы оформлены в стиле старых проектов `~/historical projects/prak1` и `~/historical projects/prak2`: группы `$CONTRL`, `$MOORTH`, `$GUESS`, `$BASIS`, `$SYSTEM`, `$SCF`, `$DATA`. Запуск использует штатный Firefly/P4 `-p4pg` с маленьким `procgrp`; по умолчанию во всех `run.sh` задано `NP=10`.
